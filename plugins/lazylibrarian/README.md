# LazyLibrarian connected library

This adapter browses an existing LazyLibrarian Book catalog and reports ebook and audiobook renditions independently. For a Book already in that catalog, it can independently change ebook or audiobook monitoring and request an exact Book search. LazyLibrarian remains the owner of its library and file placement.

Create a Connection with LazyLibrarian's base URL and API key. Enter the absolute ebook and audiobook roots as LazyLibrarian reports them, then map each provider root to a Prismedia library folder that can read the same files. The roots may map to different local folders. Open a Book from Request and switch between Ebook and Audiobook to inspect or link each rendition independently. Both links lead to the same Prismedia Book work.

The adapter is pinned to the LazyLibrarian API build identified by `2b48097a`. It verifies the reported anchor file with `getFileDirect` HEAD. For an audiobook in a reviewed mapped Book folder, it inventories the sibling M4B, M4A, and MP3 files from the local mount and reports each as a separate track; Prismedia checks every mapped path and size again before import. Files directly in the root remain separate scanner works. LazyLibrarian can return a ZIP for multi-file audio; this adapter refuses that response because it does not establish the original track paths and sizes. A Book absent from LazyLibrarian's catalog must be added there first: its name search does not establish an exact Open Library work ID. Search acknowledgement means a background search was accepted, not that a release was found; the result remains unverified until final mapped files arrive.
